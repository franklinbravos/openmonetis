<context path="src/shared/utils" updated="2026-08-11">

Funções puras e utilitários reutilizados no app inteiro. Sem dependências de domínio — qualquer módulo pode importar daqui.

## Summary

- period/ — utils de período (`YYYY-MM`): parse, ranges, soma/subtração de meses, comparação
- calculator.ts — lógica de cálculo da calculadora
- calendar.ts — formatação de datas para calendário
- category-colors.ts — cores por categoria
- currency.ts — formatação de moeda (R$) e parse
- date.ts — helpers de data (date-only, comparação)
- export-branding.ts — branding de exportações
- fetch-json.ts — helper de fetch com JSON tipado
- financial-dates.ts — datas financeiras (fatura, vencimento)
- icons.tsx — mapa de ícones
- id.ts — geração de IDs
- index.ts — barrel de utils
- initials.ts — iniciais de nome para avatar
- math.ts — helpers matemáticos (arredondamento, divisão segura)
- number.ts — formatação/parse de números
- percentage.ts — cálculos de porcentagem
- string.ts — helpers de string (slug, normalização)
- ui.ts — helpers de UI (cn, classNames)

## Constraints

- Períodos usam `YYYY-MM`; moeda é R$ com 2 casas decimais.
- Manter funções puras e sem efeitos colaterais.
