Código genuinamente reutilizado entre features. Aplica a regra: se ao deletar uma feature o arquivo deveria sumir junto, ele pertence à feature; caso contrário, vive aqui. Contém componentes de UI (incluindo shadcn/ui), hooks, lib de domínio transversal e utils.

## Summary

- components/ — componentes de UI reutilizáveis (ui, navigation/navbar, providers, brand, widgets, feedback, month-picker, logo-picker, calculator, entity-avatar, skeletons)
- hooks/ — hooks genéricos
- lib/ — helpers transversais (auth, db, actions, payers, import, storage, ai, logo, schemas, supabase, etc.)
- utils/ — funções puras (period, currency, date, math, number, percentage, string, etc.)

## Constraints

- Contratos que cruzam domínios moram aqui, nunca em uma feature.
- Tudo que é de uma única feature vai para `src/features/<feature>/`.
- Utilidades de período/currency/date vivem em `src/shared/utils/`; DB em `src/shared/lib/db.ts`.
