- actions.ts — Server Actions de categorias
- queries.ts — leituras (fetchCategoriesForUser, detalhe, histórico)
- lib/category-dnd.ts — lógica de drag-and-drop de ordenação
- components/categories-page.tsx — página de categorias
- components/categories-sortable-table.tsx — tabela ordenável com dnd
- components/category-dialog.tsx — dialog de criação/edição
- components/category-form-fields.tsx — campos do formulário
- components/category-select-items.tsx — opções de seleção de categoria
- components/create-category-inline-dialog.tsx — criação rápida inline
- components/category-detail-header.tsx — cabeçalho do detalhe da categoria
- components/category-hierarchy-name.tsx — nome com hierarquia
- components/category-icon.tsx — ícone da categoria
- components/category-picker-dialog.tsx — seletor de categoria (usado em transações)
- components/types.ts — tipos de UI

- Cores/ícones default vêm de `src/shared/lib/categories/` (constants, defaults, icons, tree).
