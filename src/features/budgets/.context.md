Feature de orçamentos por categoria. Define limites mensais de gasto por categoria e acompanha o consumo do período.

## Summary

- actions.ts — Server Actions de orçamentos
- queries.ts — leituras (fetchBudgetsForUser, fetchCategoryBudgetSummary); gasto por categoria via RPCs `get_budget_spent_by_category` e `get_category_budget_summary`
- components/budgets-page.tsx — página de orçamentos
- components/budget-card.tsx — card de orçamento (limite, gasto, progresso)
- components/budget-dialog.tsx — dialog de criação/edição
- components/types.ts — tipos de UI

## Constraints

- Mutation chama `revalidateForEntity("budgets", userId)`.
- Agregações de gasto por categoria vêm de RPCs do Supabase (filtram por `p_user_id` + `p_admin_payer_id`); selects de orçamentos/categorias continuam no bridge.
