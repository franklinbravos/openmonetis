Feature de contas bancárias. CRUD de contas, saldo e rendimento, transferências entre contas, ajuste de saldo e extrato mensal. O extrato reutiliza a página de lançamentos de `features/transactions` com filtro por conta.

## Summary

- actions.ts — Server Actions de contas (criar, editar, arquivar, excluir, transferir, ajustar saldo, registrar rendimento)
- queries.ts — leituras de contas (fetchAllAccountsForUser, fetchAccountData); saldo via RPC `get_account_balances` (Supabase) chamado uma única vez e filtrado por status em JS, fallback sem movimentações via `src/shared/lib/accounts/queries.ts` quando não há pagador admin
- statement-queries.ts — leituras do extrato (fetchAccountSummary, fetchAccountTransactionsPage, summaries por mês); agregações via RPCs `get_account_statement_summaries` e `get_account_statement_summary`
- components/accounts-page.tsx — página de contas (ativas e arquivadas)
- components/account-card.tsx — card de conta
- components/account-statement-card.tsx — card de extrato da conta
- components/account-statement-card-menu.tsx — menu do card de extrato
- components/account-dialog.tsx — dialog de criação/edição
- components/account-form-fields.tsx — campos do formulário
- components/account-select-items.tsx — opções de seleção de conta
- components/create-account-inline-dialog.tsx — criação rápida inline
- components/transfer-dialog.tsx — dialog de transferência entre contas
- components/add-yield-dialog.tsx — dialog de rendimento
- components/adjust-balance-dialog.tsx — dialog de ajuste de saldo
- components/types.ts — tipos de UI

## Constraints

- Saldo inicial é representado como lançamento com nota `INITIAL_BALANCE_NOTE` (ver `src/shared/lib/accounts/constants.ts`).
- Mutation chama `revalidateForEntity("accounts", userId)`.
- Transferências enriquecem pares via `src/shared/lib/transfers/`.
