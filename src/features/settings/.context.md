Feature de configurações da conta. Perfil (nome, e-mail, senha), preferências, tokens de API (para o Companion), provedores de IA, exclusão de conta, tab de Companion e changelog. Página em `src/app/(dashboard)/settings/`.

## Summary

- actions.ts — Server Actions de settings (atualizar perfil, preferências, senha, tokens)
- actions/ai-providers.ts — actions de configuração de provedores de IA
- queries.ts — leituras (fetchSettingsPageData, preferências, tokens)
- hooks/use-ai-model-configuration.ts — estado da configuração de IA no client
- lib/changelog-types.ts — tipos do changelog
- lib/parse-changelog.ts — parse do CHANGELOG.md
- components/update-name-form.tsx — formulário de nome
- components/update-email-form.tsx — formulário de e-mail
- components/update-password-form.tsx — formulário de senha
- components/preferences-form.tsx — preferências de exibição
- components/api-tokens-form.tsx — tokens de API
- components/ai-providers-tab.tsx — aba de provedores de IA
- components/ai-model-configuration.tsx — configuração de modelo/credenciais
- components/delete-account-form.tsx — exclusão de conta
- components/companion-tab.tsx — informações/integracao do app Companion
- components/changelog-tab.tsx — exibição do changelog

## Constraints

- Senha nova exige validação server-side; suporte a Google Auth via `src/shared/lib/auth/password.ts` (`userUsesGoogleAuth`).
- Mudanças de preferência podem revalidar o dashboard (`revalidateForEntity("notifications")` quando aplicável).
