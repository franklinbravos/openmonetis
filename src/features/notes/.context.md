Feature de anotações. CRUD de anotações com arquivamento, anexos e formatação de conteúdo. A feature de anexos de anotações é tratada aqui em `actions/attachments.ts`.

## Summary

- actions.ts — Server Actions de anotações
- actions/attachments.ts — ações de anexos de anotações (upload/remoção)
- queries.ts — leituras (fetchAllNotesForUser, ativas e arquivadas)
- lib/formatters.ts — formatação de conteúdo/data
- components/notes-page.tsx — página de anotações
- components/note-card.tsx — card de anotação
- components/note-dialog.tsx — dialog de criação/edição
- components/note-details-dialog.tsx — dialog de detalhes
- components/note-attachments-field.tsx — campo de anexos no dialog
- components/types.ts — tipos de UI

## Constraints

- Mutation chama `revalidateForEntity("notes", userId)`.
