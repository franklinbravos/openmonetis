Feature de galeria de anexos. Lista, pré-visualização e download de anexos (imagens, PDFs) com estatísticas por tipo/tamanho. Depende intencionalmente de `features/transactions`: anexos são uma extensão semântica de lançamentos.

## Summary

- queries.ts — leituras (fetchAttachmentsForPeriod, fetchAttachmentsPageData)
- hooks/use-attachment-url.ts — URL de acesso ao anexo (com autenticação)
- components/attachments-page.tsx — página de anexos
- components/attachment-grid-item.tsx — item da galeria
- components/attachment-preview.tsx — pré-visualização (imagem/PDF)

## Constraints

- Upload é via presigned URL (`src/app/api/attachments/[attachmentId]/presign/route.ts`) com whitelist de MIME (`src/shared/lib/attachments/config.ts`).
- A dependência em `features/transactions` (TransactionDialog, TransactionDetailsDialog, TransactionItem) é intencional e aceita — não mover para shared/.
- Storage em S3/Supabase via `src/shared/lib/storage/`.
