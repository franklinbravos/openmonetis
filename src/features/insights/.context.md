Feature de insights gerados por IA. Agrega dados financeiros do período, escolhe provedor/modelo de IA (OpenAI, Anthropic, Google, OpenRouter, etc.), gera análise em texto, salva insights e permite reuso. Persistência em `savedInsights`.

## Summary

- actions.ts — barrel das Server Actions de insights
- actions/aggregate.ts — agrega os dados financeiros do período para enviar à IA; agregações via RPC functions do Supabase (`get_insight_*` em `supabase/migrations/20260810000500_rpc_insights_transactions.sql`), selects simples (dayOfWeekSpending, last3MonthsTransactions) via bridge; `sumByType` é função pura exportada e testada
- actions/aggregate.test.ts — testes unit do mapeamento `sumByType` (Receita/Despesa, nulos, string/number)
- actions/generate.ts — gera o insight via provedor de IA selecionado
- actions/fetch-provider-models.ts — lista modelos disponíveis do provedor
- actions/storage.ts — persistência/carregamento de insights salvos
- actions/types.ts — tipos das actions
- constants.ts — constantes (modelo default, etc.)
- queries.ts — leituras de insights salvos
- hooks/use-saved-insights.ts — estado dos insights salvos no client
- lib/model-provider.ts — abstração de provedores de modelo
- lib/user-instructions.ts — instruções de sistema para a IA
- components/insights-page.tsx — página de insights
- components/insights-generate-panel.tsx — painel de geração
- components/insights-grid.tsx — grid de insights
- components/analysis-summary-card.tsx — card de resumo da análise
- components/model-selection-card.tsx — seleção de modelo
- components/provider-selection-card.tsx — seleção de provedor
- components/model-search-combobox.tsx — busca de modelo
- components/provider-icon.tsx — ícone do provedor
- components/opencode-plan-cards.tsx — cards de planos de preço de modelos

## Constraints

- Credenciais de provedores de IA são criptografadas e configuradas por usuário (`src/shared/lib/ai/` — env-credentials, secret-encryption, user-provider-config).
- Requer autenticação e permissão de usuário para usar o provedor configurado.
