Grupo de rotas da autenticação (não autenticadas). Páginas finas de login, cadastro, convite e o callback OAuth do Google. Os formulários e a lógica de erro ficam em `src/features/auth/`.

## Summary

- layout.tsx — layout do grupo com o sidebar visual de mock de fatura (via `AuthSidebar`)
- login/page.tsx — página de entrada
- signup/page.tsx — página de cadastro
- invite/ — página e cliente de convite para compartilhar acesso a um pagador
- invite/invite-client.tsx — componente client do fluxo de convite
- auth/google/callback/route.ts — rota de callback do Google OAuth

## Constraints

- A autenticação real é feita via Supabase Auth (`src/shared/lib/auth/*`, `src/shared/lib/supabase/*`), com proxies em `src/app/api/auth/*`.
