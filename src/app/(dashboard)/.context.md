Grupo de rotas autenticadas do app financeiro. Cada subpasta é uma página fina que busca dados e delega renderização ao componente de página da feature correspondente. O layout monta a navbar global com dados de navegação.

## Summary

- layout.tsx — layout do dashboard: sessão, navbar (`AppNavbar`), providers (preferências, privacidade, logo)
- dashboard/ — página inicial com grid de widgets editável
- transactions/ — lista de lançamentos; import/ — wizard de importação; import/history/ — histórico de importações
- cards/ — cartões; cards/[cardId]/invoice/ — fatura do cartão
- accounts/ — contas; accounts/[accountId]/statement/ — extrato da conta
- categories/ — categorias; categories/[categoryId]/ — detalhe da categoria; categories/history/ — histórico por categoria
- budgets/ — orçamentos
- payers/ — pessoas; payers/[payerId]/ — detalhe da pessoa
- notes/ — anotações
- calendar/ — calendário mensal de transações
- insights/ — insights gerados por IA
- inbox/ — pré-lançamentos (feature inbox, recebe itens do app Companion)
- attachments/ — galeria de anexos
- reconciliation/ — conciliação de extratos
- reports/ — relatórios (category-trends, card-usage, establishments, installment-analysis)
- changelog/ — changelog do app (dados vêm de CHANGELOG.md via `parseChangelog`)
- settings/ — configurações
- change-password-required/ — tela de troca de senha obrigatória

## Constraints

- Páginas aqui são finas; a lógica pertence a `src/features/*`.
- Todas as rotas exigem sessão (via `getUser()`/`getUserId()`/`getUserSession()`).
